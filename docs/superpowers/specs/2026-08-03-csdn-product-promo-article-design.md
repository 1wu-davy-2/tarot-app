# CSDN 产品宣传文章设计

## 目标

为“命运之镜”撰写一篇可直接发布到 CSDN 的产品发布型文章，提升项目认知度并引导读者体验 Web 应用或 Android APK。文章不承诺占卜结果的准确性，定位为自我记录、情绪整理和日常启发工具。

## 受众与语气

- 主要读者：对 AI 应用、效率工具、塔罗/星座或情绪记录感兴趣的 CSDN 用户。
- 语气：专业、克制、易读；以真实使用场景说明价值，避免夸大宣传和“预测未来”式表述。
- 篇幅：约 1200-1800 字，使用短段落、列表和小标题，适配移动端阅读。

## 文章结构

1. 标题与摘要：突出“AI + 塔罗 + 日常记录”的产品定位。
2. 场景引入：说明用户在记录情绪、整理问题和寻找启发时的常见需求。
3. 使用流程：抽牌、获得 AI 解读、保存记录、查看周/月报告。
4. 核心亮点：AI 塔罗解读、星座运势、塔罗日记、梦境分析、牌库与学习系统。
5. 端侧体验：介绍 Web 与 Capacitor Android APK，以及登录、通知和历史记录能力。
6. 技术背书：简述 Next.js、FastAPI、DeepSeek、Redis 和 Capacitor，不展开成教程。
7. 适用人群与使用建议：强调自我观察、复盘和娱乐性质。
8. 体验入口：保留 `[体验地址]`、`[项目地址]`、`[APK 下载地址]` 占位符。
9. 结语与反馈邀请：引导试用、留言和提交建议。

## 事实边界

文章仅使用仓库 README 和现有功能作为事实来源：78 张牌、多种牌阵、AI 流式解读、12 星座运势、日记/梦境、学习系统、Web 与 Android APK。不得虚构用户量、商业数据、上线平台或未提供的链接。

## 验收标准

- 正文可直接复制到 CSDN，Markdown 标题层级清晰。
- 卖点先于技术细节，首屏能说明产品是什么、适合谁。
- 所有外部链接均使用明确占位符，发布前可替换。
- 包含理性使用声明，不构成医疗、法律或财务建议。
